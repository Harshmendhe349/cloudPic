# CloudPic Client

React + Vite frontend for CloudPic AI Image Generation Platform.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```env
VITE_API_BASE_URL=http://localhost:8080
```

3. Start development server:
```bash
npm run dev
```

## Features

- AI Image Generation
- Image Editor with Konva.js
- Community Gallery
- Modern UI with TailwindCSS
